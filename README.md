# Stacks NFT Mint

A basic SIP-009 NFT minting DApp on the Stacks blockchain using Clarity and the Stacks SDK.

## Features
- Mint SIP-009 NFTs on-chain
- Query NFT owner
- Wallet connection with @stacks/connect
- Contract calls with @stacks/transactions

## Setup
1. Install Hiro Stacks Wallet
2. Switch to Stacks Testnet
3. Deploy `contracts/nft.clar`
4. Verify the contract on Hiro Explorer
5. Update `CONTRACT_ADDRESS` in `frontend/app.js`
6. Open `frontend/index.html` and mint an NFT (testnet)
